Schoolyard Buddies — Cloudflare Multiplayer Test

Stage 7.0.0: game static + WebSocket room server + remote 3D players.

Windows

1
Extract ZIP dan buka folder projek.
2
Buka PowerShell dalam folder dan jalankan:
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\deploy-windows.ps1
3
Log masuk Cloudflare apabila browser dibuka.
4
Buka URL https://...workers.dev yang dipaparkan.

Linux / Zorin OS

chmod +x scripts/*.sh
./scripts/deploy-linux.sh

Ujian dua pemain

  1. Buka URL game pada dua browser/peranti.
  2. Pilih nama berbeza.
  3. Buka Multiplayer.
  4. Gunakan room sama, contohnya schoolyard-main.
  5. Tekan Connect pada kedua-duanya.
  6. Tutup panel dan gerakkan pemain.
Pemain jauh akan muncul sebagai watak 3D dengan nama, penampilan, posisi dan animasi yang disegerakkan.

Buka URL Wrangler, biasanya http://localhost:8787, pada dua tab.
